# Scientific migration contract

Each comparison binds the exact source bytes, project and deposit identity, statement and scope, chemical species and material denominator, value and unit, evidence locator, and relevant dates. A reported string such as `4.10` carries different source precision from `4.1`. Original tokens and identities survive migration. Derived values carry their formula, version, input IDs and denominator.

Publication, historical availability, acquisition, estimate effectiveness and the research cutoff have distinct meanings. Evidence that postdates the cutoff cannot promote an observation. A candidate with an unresolved source, conflicting scope or inadequate evidence remains isolated while independent records continue. Accepted values require explicit versioned eligibility and selection. Candidate, validated, derived and accepted values have distinct roles.

Census cells preserve presence, missingness and applicability independently of value. A published zero is present. Null-like source states remain distinct and a blank cell has its own status. The archived Census uses 3,034 as the historical applicability denominator and 3,028 as the reclassified denominator. The latter reflects six fields reclassified as not applicable.

The independent Oracle compares observable migration behavior against immutable V2 artifacts. Exact identity, lexical precision, scope, date, provenance, cell state and rank are required. Declared derived decimal precision and declared floating-point methods have explicit comparison policies. Model accuracy and recall require independent annotation.
