## 固定網站與發布

附帶的舊版 ZIP 已檢查版面與控制項。網站沿用地圖側欄、選擇量測群組、搜尋、排序、篩選、點選證據、切換中英及雙案比較的互動方向。專案、科學值和位置來自所選 V3 版次的 JSON。地圖有 Natural Earth 底圖，以及合格礦場／礦床點的專用輸出。兩個實際候選的合格位置均為 0。MCDA 只顯示一個兩案的已計算面板，其餘四個面板保留樣本不足。

同一組 HTML、CSS 和 JavaScript 顯示舊候選 105 格與新候選 1,104 格。每次載入核對完整 manifest、SHA-256、版次與關聯後才換版。瀏覽器實際測了 51 欄、查詢篩選、排序、CSV 原始 SHA、觀測證據、地圖、雙案、MCDA、排名敏感度、語言、手機、來源 XSS、缺檔、混版及新版本提示。瀏覽器實測使用 Playwright 的隔離 HTTP(S) 回應，受控預覽檔可用本機 HTTP 開啟。[前端與重跑方式](../../web/README.md)

正式頁預設讀 `data/latest.json`，兩份候選的入口是明確的 `?preview=1`。發布服務以現有合格 F5 與發布授權導出完整站台，先驗證所有檔案，再推進指標。兩種故障注入核對前版完整檔案和指標均保留。以真實候選執行正式建置時，因獨立備份缺失而拒絕，正式 `latest.json` 仍不存在。GitHub Pages 查詢回傳 404，部署授權查詢回傳 403，實際部署為 `BLOCKED`。CI 使用合成資料瀏覽器測試，手動檢查工作流只上傳純空狀態。[發布接線](web_release_linkage.md)

## 工程量測

同一封存 Store 的既有投影流程，各進行五次獨立 Python 程序及一次剖析。基準→A→修正後 B 的耗時中位為 0.206→0.215→0.281 秒，Python 峰值 RSS 為 30,760→30,768→31,100 KiB。三件投影產物仍逐位元組一致。到達模組間動態呼叫邊為 10→10→11，靜態 import 邊為 23→26→43。AST 最大分支分數維持 30，第 90 百分位由 17 增至 19；量測路徑的跨模組重複函式體群為 0。執行時仍有 OS 快取和並行 QA 波動。[同工作量逐次收據](census_projection_engineering.json)

實際 144 原件的獨立 A/B 完整建置增加投影責任，使用獨立工作量記法。固定 Chromium 的最新候選 Census 顯示為 514 ms、歷史切換為 154 ms、載入後 JS heap 約 8.64 MB，使用受控 HTTP(S) 測試回應。四個 JavaScript 模組有四條靜態相依邊、AST 分支上限／第 90 百分位 29／8，跨模組重複函式體群為 0。既有等功能瀏覽器成本、頁面 RSS 及 GitHub 計費仍為 `UNMEASURED`。本機完整套件實際執行 254 項、全數通過、無跳過，耗時 39.156 秒。[JavaScript 工程收據](census_static_web_engineering.json) · [原件、CI 與封裝收據](census_web_verification.json)
